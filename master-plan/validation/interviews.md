# Validation Log

One row per conversation. Use the same questions for every interview so the answers can be compared. Results feed the Phase 1 re-score (`../00_SCORING_FRAMEWORK.md` §5).

**Core questions (all tracks)**
1. Tell me about the last time this happened. (Don't pitch first.)
2. What did it cost you in time, money or stress?
3. What do you use today? What do you pay for it?
4. (Show the demo) Would you try this? On what, and when?
